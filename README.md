# Estebanquito - Plataforma Bancaria Web

Proyecto integrador para el curso de Desarrollo Web.

## 🚀 Descripción
Estebanquito es una aplicación web diseñada para ofrecer servicios bancarios en línea. Los usuarios pueden:
- Gestionar sus cuentas.
- Realizar transacciones (transferencias, depósitos, retiros).
- Solicitar préstamos.
- Consultar su historial financiero.

La plataforma debe ser intuitiva y accesible para los usuarios.

## 🛠️ Tecnologías utilizadas
- React.js (Frontend)
- Node.js con Express (Backend)
- Mongo DB (Base de datos)
- Git y GitHub para control de versiones

## ✅ Funcionalidades principales
1. Registro y Autenticación
2. Gestión de Cuentas
3. Transacciones
4. Solicitudes de Préstamos
5. Reportes Financieros

## 📂 Modelos del negocio
Usuarios, Transacciones, Préstamos, Reportes

## ▶️ Instalación y ejecución
1. Clona el repositorio:
   git clone https://github.com/mc4mi/Estebanquito.git
2. Instala dependencias:
   npm install
3. Inicia el servidor:
   npm start

## 🔑 Variables de entorno
DB_HOST, DB_USER, DB_PASS, DB_NAME
